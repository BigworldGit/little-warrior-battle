# 小战士大冒险 - 双人对战版

🌟 在线多人对战游戏

## 简介

这是一个支持在线双人对战的 HTML5 游戏，玩家可以与好友实时对战。

## 功能特点

- 🎮 实时双人对战（Socket.io）
- 🤖 离线练习模式（AI 机器人陪练）
- ⚔️ 9 种风格迥异的武器随机切换，每种武器带多段连击（三连斩/组合拳/跳劈/突刺横扫）
- 🦾 重做的角色系统：两段式手臂腿部关节、分层盔甲、披风波浪、走路/待机/受击/倒地全动画
- 🌿 全 3D 竞技场：风吹草地、日光天空、漂浮萤火
- 🥊 打击感强化：打击停顿、屏幕震动、慢动作 KO、伤害飘字
- 🕹️ 支持键盘和触屏控制
- 🔊 WebAudio 合成音效与背景音乐（无需外部音频资源）

## 安装与运行

```bash
# 安装依赖
npm install

# 启动服务器
npm start
```

然后在浏览器打开 `http://localhost:3000`

## 操作说明

### 键盘控制
- `A` / `D` 或 `←` / `→` - 左右移动
- `E` / `J` / `空格` - 攻击
- `W` / `K` / `Shift` - 闪避
- `Q` - 随机切换武器（5 秒冷却）

### 触屏控制
- 左侧虚拟摇杆 - 移动
- ⚔️ 按钮 - 攻击
- 🏃 按钮 - 闪避
- 🔄 按钮 - 切换武器

## 技术栈

- Node.js + Express
- Socket.io (WebSocket 实时通信)
- Three.js 3D 渲染
- OpenAI Images 离线美术资产流水线（见 `docs/openai-images-art-pipeline.md`）

## 3D 化方向

当前版本已经升级为动态 3D 视角：包含更丰富的竞技场、儿童友好的玩具感小战士、前后位移、动态镜头、柔和光照、接触阴影、星光命中特效，并预留 `public/assets/ai/manifest.json` 用于加载 OpenAI Images 生成的高质量贴图资产。

生成 AI 美术资产：

```bash
OPENAI_API_KEY=... npm run generate:ai-assets
```
