# 小战士大冒险 - 双人对战版

🌟 在线多人对战游戏

## 简介

这是一个支持在线双人对战的 HTML5 游戏，玩家可以与好友实时对战。

## 功能特点

- 🎮 实时双人对战
- ⚔️ 多种武器选择
- 🕹️ 支持键盘和触屏控制
- 💾 断线重连支持

## 安装与运行

```bash
# 安装依赖
npm install

# 启动服务器
npm start
```

然后在浏览器打开 `http://localhost:3000`

## 操作说明

### 键盘控制
- `WASD` 或 `方向键` - 移动
- `J` 或 `空格` - 攻击
- `K` 或 `Shift` - 闪避
- `E` - 切换武器

### 触屏控制
- 左侧虚拟摇杆 - 移动
- ⚔️ 按钮 - 攻击
- 🏃 按钮 - 闪避
- 🔄 按钮 - 切换武器

## 技术栈

- Node.js + Express
- Socket.io (WebSocket 实时通信)
- HTML5 Canvas
